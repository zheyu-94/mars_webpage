# MARS 2035

A cinematic static landing page for a fictional Mars travel experience.

## Preview Locally

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/index.html`.

## Files

- `index.html` - page structure
- `styles.css` - visual design and responsive layout
- `script.js` - canvas Mars globe, counters, reveal effects, and cabin interactions
